I want to build this: {{args}}

Don't write code yet. First:
1. Find the code this touches (search, outline, read the relevant ranges).
2. Propose an approach in a few sentences, including what you considered and rejected.
3. List the files you'd change and what changes in each.
4. Call out risks: migrations, breaking changes, performance, security.
5. Describe how you'll test it.

Record the steps with the plan tool. If something is genuinely ambiguous, ask me at most three questions. Then stop and wait for me to say go.
